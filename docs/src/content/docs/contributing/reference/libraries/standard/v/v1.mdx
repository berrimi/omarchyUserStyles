## Usage

```less
@import "https://berrimi.github.io/omarchyUserStyles/lib/std/v1.less";
```

## API

The standard library exposes a `#lib` namespace.

### `#lib.palette()`

The standard library palette mixin provides Less variable definitions that resolve to the user's Omarchy theme variables (`var(--omarchy-*)`) at runtime, plus static CSS filter strings for recoloring icons. There is a single `omarchy` flavor. Call the mixin at the top of the `#omarchy` mixin to inject the variables into the userstyle context. This is used in all userstyles.

The accent variable follows the user's `accentColor` option:

```less
@accent; // -> var(--omarchy-purple) (or whichever accent is selected)
```

Because the palette resolves at runtime, Less color functions (`fade()`, `lighten()`, `mix()`, …) cannot be used on palette variables. Use [`color-mix()`](https://developer.mozilla.org/en-US/docs/Web/CSS/color-mix) and [relative colors](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_colors/Using_relative_colors) instead:

```less
color-mix(in srgb, @accent 30%, transparent);
from @base r g b; /* channel fragment, consumed as rgb(var(--x)) */
```

### `#lib.defaults()`

The standard library defaults mixin provides a set of default styles for text selection and native/input elements. This is generally applied in all userstyles, with some exceptions.

### `#lib.css-variables()`

The standard library CSS variables mixin provides the palette variables in [CSS variable/custom property](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_cascading_variables/Using_CSS_custom_properties) form (as `--omarchy-*` aliases). This is commonly used alongside [syntax highlighting imports](/contributing/guides/syntax-highlighting/).
